# Справочник инструментов Holix Office

Имя сервера — `holix-office`. Каждый путь считается от `HOLIX_OFFICE_WORKSPACE`. Удачная правка возвращает `ok: true` и, если файл открыт в Holix Studio, поле `editor_refresh`. Отказ возвращает `ok: false` и `error`.

Не распаковывайте документ и не переписывайте XML в оболочке. Так Studio не узнает о правке, и пакет можно повредить.

## office_list_tool

Без аргументов. Возвращает `files` и `count` для `.docx`, `.xlsx`, `.pptx`, `.odt`, `.ods` и `.odp` в рабочей папке. Скрытые и служебные каталоги вроде `.git`, `node_modules` и `.venv` пропускаются. Список обрывается на 200 файлах.

## office_read_tool

| Аргумент | Смысл |
|---|---|
| `path` | Документ, например `reports/plan.docx` |
| `max_chars` | Предел текста. По умолчанию 40000 |

Возвращает склеенный текст абзацев, фигур на слайдах, общих строк и текстовых узлов ODF. Числа Excel, которые лежат только в `<v>`, в этот текст не попадают. Их читает `office_sheet_tool`.

## office_replace_tool

| Аргумент | Смысл |
|---|---|
| `path` | Документ |
| `old` | Точный текст |
| `new` | Замена. Можно передать пустую строку |

Фраза в одном фрагменте сохраняет его оформление. Фраза, разрезанная по нескольким фрагментам одного абзаца, записывается в первый текстовый узел этого абзаца. Поле `replaced` — число замен. Если совпадений нет, редактор не обновляется.

Меняются: документ DOCX, сноски, концевые сноски, комментарии, колонтитулы; слайды и заметки PPTX; общие строки и листы XLSX; `content.xml` у ODT, ODS и ODP.

## office_format_tool

| Аргумент | Смысл |
|---|---|
| `path` | Документ |
| `text` | Точная фраза |
| `font` | Семейство, например `Calibri` |
| `size` | Пункты: `14` или `14pt`. Больше 0 и не больше 500 |
| `bold`, `italic`, `underline` | Задать или не трогать. Пропущенное свойство не меняется |
| `color`, `fill` | `RRGGBB`. Значение `auto` отклоняется |
| `style` | Именованный стиль абзаца, например `Heading 1`. Только DOCX и ODT |

Нужно хотя бы одно свойство. Полужирный, курсив, подчёркивание, цвет, шрифт и размер применяются к каждому совпадению фразы. `fill` закрашивает абзац только когда весь его текст без краевых пробелов равен фразе. На XLSX шрифт и заливка применяются к ячейке, чьё значение или формула содержит фразу. На ODS и ODP те же свойства пишутся стилями ODF. Если на XLSX, PPTX, ODS или ODP запрошен только именованный стиль, инструмент возвращает ошибку.

## office_append_tool

| Аргумент | Смысл |
|---|---|
| `path` | DOCX или ODT |
| `text` | Текст абзаца |

Остальные типы возвращают ошибку. Содержимое туда добавляют `office_sheet_tool` и `office_slide_tool`.

## office_media_tool

| Аргумент | Смысл |
|---|---|
| `path` | Документ |
| `media` | Картинка или видео внутри рабочей папки |
| `slide` | Слайд с 1 или номер листа для XLSX |
| `width_cm`, `height_cm` | Размер кадра. По умолчанию 12 и 6.8 |

Картинки: png, jpg, jpeg, gif, webp, bmp, tiff. Видео: mp4, m4v, webm, mov, ogg. Предел размера — 200 МБ.

Видео воспроизводится на слайде PPTX, странице ODP и в кадре ODT. DOCX кладёт байты в `word/media/` и добавляет абзац со ссылкой. XLSX и ODS видео не принимают. Картинка XLSX ставится на выбранный лист.

## office_slide_tool

PPTX и ODP. `slide` считается с 1.

| `action` | Эффект |
|---|---|
| `list` | Слайды и их текст. Файл не перезаписывается |
| `add` | Новый слайд. `layout` для PPTX: `title`, `title_body`, `section`, `two`, `title_only`, `blank` |
| `set` | Заменить заголовок и текст слайда `slide` |
| `notes` | Заменить заметки докладчика. У ODP это текстовый блок |
| `delete` | Удалить слайд `slide` |

`title`, `body` и `notes` — тексты для `add`, `set` и `notes`. Шрифт уже написанного текста слайда меняет `office_format_tool`. Картинки — `office_media_tool`. Анимации, переходов и мастер-слайдов нет.

## office_sheet_tool

XLSX и ODS.

| `action` | Эффект |
|---|---|
| `list` | Имена листов |
| `add` | Создать лист `sheet`. Имя не длиннее 31 символа |
| `read` | Значения и формулы, не больше 400 ячеек |
| `set` | Записать `value` в `cell` на листе `sheet`. Числовые строки становятся числами |
| `formula` | Записать `formula`. Принимаются `=Other!A1` и `=SUM(A1:A2)`. ODS хранит `of:=[Other.A1]` и `of:=SUM([.A1:.A2])` |
| `link` | Гиперссылка в `cell`. Адрес передаётся в `link` |
| `name` | Именованный диапазон XLSX. Имя передаётся в `sheet`, диапазон вроде `Sheet1!$A$1:$B$10` — в `range_ref`. Для ODS именованные диапазоны отклоняются |

`list` и `read` редактор не обновляют.

## office_chart_tool

| Аргумент | Смысл |
|---|---|
| `chart_type` | `bar`, `column`, `line` или `pie` |
| `path` | XLSX или PPTX |
| `sheet` | Лист XLSX |
| `data_range` | Ряд XLSX вместе с ячейкой названия, например `B1:B4` |
| `categories_range` | Подписи XLSX, например `A2:A4` |
| `anchor` | Ячейка, где стоит диаграмма. По умолчанию `E2` |
| `title` | Название диаграммы |
| `slide` | Слайд PPTX, с 1 |
| `categories`, `values` | Для PPTX списки одной длины через запятую, например `Jan,Feb` и `10,12` |
| `series_name` | Имя ряда на PPTX |

В ODS и ODP диаграммы не записываются.

## office_table_tool

| Аргумент | Смысл |
|---|---|
| `action` | `read`, `add` или `set` |
| `rows_json` | JSON-список строк для `add`, например `[["Name","Qty"],["A","1"]]` |
| `table` | Номер таблицы с 1 для `read` и `set` |
| `row`, `col` | Ячейка с 0 для `set` |
| `value` | Новый текст ячейки для `set` |
| `slide` | Слайд PPTX или ODP, с 1 |
| `header` | Первая строка — заголовок. По умолчанию да |

`add` принимает не больше 200 строк и 40 столбцов. На XLSX `add` пишет сетку с A1 и создаёт таблицу Excel. На ODS `add` пишет сетку на первый лист. Одна ячейка через `set` меняется в DOCX, PPTX, ODT и ODP. `read` редактор не обновляет.

## Ошибки, которым можно верить

| Сообщение | Что изменить |
|---|---|
| Path must stay inside the workspace | Относительный путь внутри рабочей папки |
| Path must be a docx, xlsx, pptx, odt, ods, or odp file | Цель не входит в шесть типов |
| Named styles are available for docx and odt | Уберите `style` или возьмите DOCX/ODT |
| Appending a paragraph supports docx and odt | Для листа или слайда нужен другой инструмент |
| Charts are not written into ods or odp | Возьмите XLSX или PPTX |
